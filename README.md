# Discord Bot

Bot de Discord com:
- Comandos slash (`/ping`, `/coinflip`, `/tigrinho`, `/perfil`, `/carteira`)
- IA via Groq (`/ia pergunta`)
- Sistema de eventos com botões e pontos
- Gerenciamento de cargos (`/cargoedit`, `/menucargo`)
- Lock/unlock de canais

## Setup

1. Clone o repositório
2. `npm install`
3. Copie `.env.example` para `.env` e preencha os valores
4. `npm run dev`

## Deploy

Hospedado no [Render](https://render.com). Variáveis de ambiente configuradas no Dashboard.
